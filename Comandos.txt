Comandos

Iniciar entorno
bash start-docker.sh start
bash start-docker.sh open

Agregar Mensajes
1)
cd /root/ros2_ws/src/sim_ros2_interface

2)
nano meta/interfaces.txt

Agregá al final una línea nueva:

robmovil_msgs/msg/MultiEncoderTicks
robmovil_msgs/msg/EncoderTicks
rosgraph_msgs/msg/Clock
sensor_msgs/msg/Imu
nav_msgs/msg/MapMetaData
nav_msgs/msg/OccupancyGrid
geometry_msgs/msg/PoseStamped
geometry_msgs/msg/PoseArray

Guardá con Ctrl + O, Enter, y salí con Ctrl + X.

3)
nano package.xml

Buscá donde están las demás dependencias y agregá una nueva:

<depend>robmovil_msgs</depend>

4).
nano CMakeLists.txt

Buscá la línea con otros find_package(...) y agregá:

find_package(robmovil_msgs REQUIRED)

Buscá donde se hace ament_target_dependencies (probablemente en algo como ament_target_dependencies(simROS2 ...)) y agregá robmovil_msgs dentro de los argumentos, por ejemplo:

ament_target_dependencies(simROS2
  robmovil_msgs
)

5)
cd ~/ros2_ws

colcon build --packages-select robmovil_msgs
source install/setup.bash
colcon build --packages-select sim_ros2_interface
source install/setup.bash

Compilar todo
 
colcon build
source install/setup.bash
